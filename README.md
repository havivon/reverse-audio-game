# אחורנית: משחק אודיו הפוך

משחק מסיבות לאנדרואיד: מקליטים משפט, שומעים אותו הפוך, מחקים את הגרסה ההפוכה,
והאפליקציה הופכת את החיקוי בחזרה. אם החיקוי טוב, שומעים את המשפט המקורי.

## התקנה
הורידו את `dist/achoranit.apk` לטלפון, פתחו אותו ואשרו "התקנה ממקורות לא ידועים".
בהקלטה הראשונה האפליקציה תבקש הרשאת מיקרופון.

## תכונות
- הקלטה (עד 15 שניות) או טעינת קובץ שמע, עם השמעה רגילה והפוכה
- ציון דמיון משוער (MFCC + DTW) בין המקור לבין החיקוי ההפוך
- מצב קבוצתי: שחקנים, תורות, ניקוד ומשפט סודי שאפשר להסתיר
- משפטי אתגר בשלוש רמות קושי, ושליטה במהירות ההשמעה
- שיתוף התוצאה כקובץ WAV (המקור ואחריו התוצאה)
- הכול עובד בלי אינטרנט, וההקלטות לא יוצאות מהמכשיר

## מבנה
- `web/index.html`: המשחק עצמו (HTML/JS, Web Audio API). אפשר לפתוח אותו גם בדפדפן.
- `android/`: מעטפת WebView נייטיב (Java) שמגישה את `web/` מתוך ה-assets.
- `build-apk.sh`: בונה APK חתום בלי Gradle ובלי Android Studio.
- `.github/workflows/apk.yml`: בונה APK בכל push ומעלה אותו כ-artifact.

## בנייה
```bash
sudo apt-get install android-sdk-platform-23 aapt apksigner zipalign dalvik-exchange openjdk-17-jdk
./build-apk.sh   # → dist/achoranit.apk
```
מפתח החתימה (`android/release.keystore`) נוצר בבנייה הראשונה ולא נשמר ב-git.
כדי לעדכן גרסה מותקנת בלי למחוק אותה, צריך לבנות עם אותו מפתח ולהעלות את `VERSION_CODE`.
